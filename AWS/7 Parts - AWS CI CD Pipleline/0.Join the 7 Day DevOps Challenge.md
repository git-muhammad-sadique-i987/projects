### What is DevOps?

DevOps i is all about getting teams to build and deploy code faster without sacrificing reliability. It is a set of practices that combines development (writing code) and operations (deploying and maintaining code) to shorten development cycles and deliver reliable software.

DevOps engineers implement DevOps practices in their organization. They build automated pipelines, containerize applications and turn cloud infrastructure into code.

### What is CI/CD?

CI/CD stands for Continuous Integration/ Continuous Development. This process helps teams shortening Development life cycle by deploying small and frequent code changes after series of automated tests are being applied to the code using different tools.
